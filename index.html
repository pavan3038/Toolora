    Frequently asked questions

    Is Toolora really free?

    Yes. Every tool is free to use as often as you like, with no signup, no watermarks and no daily limits.

    Are my files uploaded to a server?

    No. Image, text, JSON and calculator tools run entirely in your browser, on your device. Your files and text are not uploaded, and nothing is stored after you leave the page. You can confirm it yourself by watching your browser’s network tab while using a tool.

    Do I need to create an account?

    No. There are no accounts. Favourites, recently used tools, your theme and your language are remembered only in your own browser.

    Which devices and browsers work?

    Any modern browser on phones, tablets and computers — current versions of Chrome, Edge, Firefox and Safari. A few features depend on the browser; for example, Safari cannot save WebP images, so that option is turned off there.

    Can I use Toolora in Hindi?

    Yes. Use the language menu at the top of any page to switch between English and हिन्दी. The tool interfaces are translated; longer help articles are currently in English. More languages can be added over time.

    How is Toolora funded?

    Toolora is currently a free project with no advertising and no tracking. If that ever changes, for example with unobtrusive ads, we will explain it in the Privacy Policy first.

    How can I suggest a tool or report a problem?

    Use the “Send feedback” link in the footer of any page. New tools are being added step by step — more PDF tools and more calculators are next on the list.
