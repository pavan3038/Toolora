      How to use Image Resizer

      1. Choose an image — drag it onto the box, click to browse, or paste it from your clipboard.
      2. Enter a new width or height in pixels (the other side follows automatically), or switch to percentage. Quick-size buttons set common widths in one click.
      3. Check the preview and the new file size, then download your resized image.

      About Image Resizer

      Resizing changes how many pixels an image contains. Smaller images load faster, fit upload limits and suit the exact slot they will be displayed in — a profile picture, a blog header or an email banner. Larger images can fill bigger screens or prints, although enlarging cannot add detail that was never captured.

      Keep “lock aspect ratio” switched on to preserve the picture’s proportions: change the width and the height is calculated for you. Switch it off only when you want to deliberately stretch the image to a new shape — stretching changes how people and objects look. If you need a different shape without distortion, the right tool is cropping rather than resizing.

      When making an image smaller, Toolora scales it down in steps and uses high-quality smoothing, which keeps edges and text sharper than a single large jump. Enlarging an image makes it softer, so you will see a reminder when your new size is bigger than the original. Output can be JPEG, PNG or WebP; JPEG and WebP have a quality slider, while PNG is lossless.

      Need a smaller file size rather than smaller dimensions? Resize first to the size you actually need, then run the result through the Image Compressor for the best results.

      How your data is handled

      Your image is resized by your browser on your own device. It is never uploaded, and nothing is stored after you close or reset the page.

      Image Resizer – frequently asked questions

      Does resizing reduce image quality?

      Making an image smaller keeps it sharp at the new size, but you lose the extra pixels. Making it larger cannot add real detail, so it looks softer. For best results, avoid enlarging by a large factor.

      Why does my resized image look stretched?

      You probably unlocked the aspect ratio and entered both a width and a height that do not match the original shape. Turn on “lock aspect ratio” and change only one side.

      Can I resize to an exact file size such as 100 KB?

      Resizing sets dimensions, not file size. To hit a size target, resize to the dimensions you need and then use the Image Compressor’s quality slider.

      What is the largest size I can create?

      Up to 10,000 pixels on either side and about 64 megapixels in total, which is more than most devices can comfortably handle anyway. The input file can be up to 25 MB.

      Which formats are supported?

      You can open JPG, PNG and WebP files and save the result as JPEG, PNG or WebP. Some browsers, such as Safari, cannot save WebP, in which case that option is disabled.

      Is my image uploaded anywhere?

      No. All processing happens in your browser on your device.
